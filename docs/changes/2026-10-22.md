## Pitfall found — quote-stripping minifier caused a false negative

My first verification grepped `href="/zh/posts/..."`. Hugo's `--minify` **strips attribute quotes**,
so the pattern matched 0 times and the links looked broken. The links were fine — 11 `<a>` tags were
present on the page. Correct probe:

```
grep -oE 'href=[/"]*(zh/)?posts/<slug>/?' public/zh/posts/<sibling>/index.html
```

**This is the same class as the skill's existing "a zero-count from one regex is a hypothesis, not a
finding" rule.** Recorded so the next session does not "fix" a non-bug.
