# 2026-11-22 — Footer studio network (site was a dead end)

## Why

Portfolio-wide audit found zero outbound links between any of the studio's properties.
`builderdecade.com` linked to nothing but Hugo, GitHub and AdSense.

## What changed

`layouts/_partials/footer.html` — added the studio-network block:

```
Also from IdeaFactory: IdeaFactory · Train Decade · Instagram
```

All tagged `utm_source=builderdecade&utm_medium=referral&utm_campaign=footer`.
New i18n key `also_from` in both `i18n/en.yaml` and `i18n/zh.yaml`.

## ⚠️ Two footer partials exist — only one renders

```
layouts/partials/footer.html     ← stale duplicate, NOT used
layouts/_partials/footer.html    ← the one modern Hugo renders  ✅ edited this one
```

The first edit went to the wrong file. `hugo --quiet` exited **0** and the build silently
lacked the change — caught only by grepping rendered output.

**Rule: `hugo` exit 0 is not evidence a partial is live. Assert on rendered HTML.**
The comment in the edited partial now says so in place.
