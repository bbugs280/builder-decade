## Open
- Cover was regenerated FOUR times. Root cause: Wan2.6 stamps a vintage-brand name on any
  analog gauge dial ("FLECHTNER"/"FLECHER"/"ELECTRO-GEN" across V1–V3) and stamps ledger text on
  any card/receipt ("Livrat tur rice" V1, "Feat Rate / STOCK/UNIT/TOTAL" V4). Prompt negation
  ("NO lettering, NO words") does NOT remove it — the model can't separate "vintage brass gauge"
  from "has a manufacturer name." **The fix was to remove every text-carrier object** (no dial
  face, no card, no receipt) and let the metaphor live in a glowing pure-light arc/needle + a
  blank unlabelled knob. V5 verified text-free by two independent vision passes ("zero text found").
  This is the same class as the documented directionality trap: re-prompting more literally does
  not fix it — only removing the offending object does.
- Site-wide CTR remains the unsolved lever (~0 EN clicks / 30d). This post gets a terminal action,
  but the acquisition/authority gap is a separate decision (see `one-person-team` backlink note in 2026-10-01.md).
- ZH title is a semantic mirror of EN but not a literal translation (per site convention).
