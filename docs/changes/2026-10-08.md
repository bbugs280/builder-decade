## The solo-calc `scope` mode
- **File:** `layouts/shortcodes/solo-calc.html` — 4th `else if eq $mode "scope"` branch
  in the fields chain + new `updateScope()` in the JS + dispatch wired.
- **Three select inputs:** reversibility (0/1/2), blast radius (0/1/2), stakes (0/1/2).
- **Grade rule:** `max(rev, blast, stakes)`, plus a **floor** — `rev >= 2 && blast >= 1`

## ⚠️ Pitfall found + fixed (worth remembering)
The post first wrapped the shortcode in `<figure>…</figure>`. **Hugo's Goldmark config
here strips raw HTML** (`WARN Raw HTML omitted while rendering …`), and it swallowed the
shortcode inside — the calculator rendered as *nothing*. Fix: call the shortcode **bare**,
exactly as `metered-build` does. Signal to watch: a `WARN Raw HTML omitted` line in the
build output plus a shortcode that renders 0 bytes.
