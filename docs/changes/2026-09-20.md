## Changes

### 1. New post: "Your Agent Trusts Everything You Connected It To" (EN + ZH)
Solo-builder-altitude piece on MCP trust boundaries — the first **security** node on
builderdecade, and the first post in the site's expanded scope that isn't software-adjacent-in-the-generic-AI sense.

- Thesis: the trust gap is structural, not a bug. Tool *descriptions* are reviewed once at
  connect time; tool *responses* get no equivalent check, and the model can't reliably
  distinguish data from instructions.
- Spine: OWASP "MCP Tool Poisoning" attack reference + OWASP MCP Top 10 (MCP03:2025);
  CSA research note 2026-07-01 (IDE auto-execution; MCPTox benchmark — 45 servers / 20 models /
  **36.5% avg attack success, 72.8% peak**; Invariant Labs April 2025 SSH-key PoC via a poisoned
  *calculator* tool description; MCPoison CVE-2025-54136; CurXecute CVE-2025-54135).
- Fully anonymous. No first-person receipts, no named stack, no product/employer references.
- Cross-links (both directions, EN + ZH): `done-is-a-claim` (verify *output* vs this post's
  verify *input*), `what-agents-cant-do` (capability ceiling), `api-vs-mcp` (transport ≠ safety).

### 2. New terminal action — `layouts/shortcodes/mcp-audit.html`
**This is the site's FIRST terminal action. Coverage was 0 of 74 posts before this change.**

An interactive, fully client-side audit the reader runs against their *own* config:

- 3 copy-to-clipboard `grep` commands (zero-width characters, sensitive paths, exfiltration shapes)
  drawn from OWASP's published static detection indicators.
- A 5-statement exposure self-score that tallies live and returns a banded verdict
  (0 = clean → 4-5 = "your agent is a single point of failure") with a next action per band.
- No backend, no network calls, no data leaves the browser — deliberate, given the subject matter.

### ⚠️ Two convention corrections found and applied
1. **ZH cross-links: use plain markdown paths, NOT `{{< ref >}}`.** My first ZH draft used
   `{{< ref "/zh/posts/<slug>" >}}`, which fails the build with `REF_NOT_FOUND` — inside a ZH
   file Hugo resolves `ref` relative to the language, so the `/zh/` prefix double-counts. **No
   other ZH post on this site uses `ref`**; all 37 use `/zh/posts/<slug>/` markdown links. Switched to match.
2. **Cover image path is a bare filename**, e.g. `cover-<slug>.png`, NOT `/<cover-...>`.
