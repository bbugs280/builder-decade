Recovered a post that was left half-shipped in the working tree for five days,
and closed the site's only EN/ZH parity gap. Content + asset work only — no

Two commits:
- `3e17f25` — Add `decisions-are-correlating` post (EN) + cover, fix Sources heading
- `e8dde1f` — Add ZH twin; internal-link the EN post

## What was wrong (three separate defects)
1. **Uncommitted post.** `content/posts/decisions-are-correlating.md` existed in
   the working tree, dated 2026-10-07, `draft: false` — but was **never
   committed**. Last commit before recovery was 2026-10-09. The post would have
   been lost with the working tree.
   ⚠️ Note: the builderdecade discovery cron's 2026-10-12 report counted this
   post as live ("three shipped since: `metered-build`,
   `decisions-are-correlating`, `trust-scope-reversibility`"). It was not in git.
2. **Missing cover.** Its frontmatter referenced
   `cover-decisions-are-correlating.png`, which did not exist in `assets/` —
   44 covers existed for 45 posts. Would have rendered a broken cover.
3. **Malformed Sources heading.** The file ended with a bare `Sources` followed
   by a stray `---`, where every other post uses `## Sources`.

## The fix

### 1. Heading → repo convention
`Sources\n---` → `## Sources`. Now renders as `<h2 id=sources>`, byte-identical
in structure to `trust-scope-reversibility`.

### 2. Cover image — two prompt iterations to satisfy the no-text rule
New cover generated via `scripts/gen_dashscope.py` (DashScope Wan2.6-t2i),
1344×768 — matching every existing cover.

⚠️ **Pitfall recorded:** the house style forbids lettering. The first two drafts
both rendered **dial faces with numerals**, despite the prompt explicitly
saying "no numbers, no dial markings" — the model strongly associates
"gauge/dial/instrument face" with markings. Fixed by changing the *object*
rather than fighting the prompt: unmarked brass-capped vessels instead of
gauges. **Lesson: when the model won't obey a negative constraint on an object
category, change the category.**

Verified via `vision_analyze` (third pass): no numerals, no letters, no printed
text; two faintly tick-marked gauges exist only in deep background blur.

- `assets/cover-decisions-are-correlating.png` — new (1.48 MB)
- `scripts/prompts_dashscope.py` — added `decisions-are-correlating` prompt
- EN frontmatter `alt` rewritten to describe the actual image (the original alt
  described a design that was never made: "a hundred identical screens")

### 3. ZH twin — closes the parity gap
`content-zh/posts/decisions-are-correlating.md` — new Traditional Chinese twin,
written to the site's house register (口語/casual, not machine-translated).

- Site was **45 EN / 44 ZH** before; now **45 / 45**.
- Shares the same cover asset as the EN post — per repo convention, EN and ZH do
  **not** carry separate cover images (confirmed against
  `trust-scope-reversibility`, `one-person-team`).

### 4. EN post had ZERO internal links
`content/posts/decisions-are-correlating.md` mentioned `harness-not-model` in
backticks — a bare mention, not a link. Site convention links liberally. Now
`[harness-not-model](/posts/harness-not-model/)`.

This matters because internal links are one of the three stated levers for this
site: **tune → internal links → terminal action → backlinks** (see
`decade-content-pipeline`).
