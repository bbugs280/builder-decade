GSC query rows** — unlike traindecade, whose ZH lane is its only converting surface.
That reasoning is sound, and it was overridden, not refuted.

**founder-naming cluster is the only cluster on this site that has ever produced a

twin lands in the one cluster with demonstrated demand, rather than being a blind bet
across the whole site.

⚠️ **Recorded explicitly so the next run does not re-litigate it.** Both positions are
defensible; the human gate chose parity. If ZH traffic does not appear in GSC within
~6 weeks, that is the test result — not a reason to revert mid-way.
