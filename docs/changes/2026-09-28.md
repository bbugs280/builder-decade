# 2026-09-28 — builderdecade: remove duplicate H1 across 22 posts

## Why
The weekly GSC foothold pull (Stage 1, decade-content-pipeline) surfaced the site's best
foothold — and a structural defect behind its 0% CTR:

```
EN  when-to-hire-your-first-contractor   0 clk / 18 impr / pos 5.1   ← page 1, top half
EN  one-person-team                      0 clk /  7 impr / pos 3.4
EN  seo-for-indie-hackers                0 clk /  6 impr / pos 5.3
EN  solo-founders-winning                1 clk /  6 impr / pos 4.2
```
Ranking is NOT the problem — these sit in the top half of page 1 with `ctr: 0`. Inspecting the
rendered page found the cause candidate: **two `<h1>` elements on one page.**

## The defect
The PaperMod theme renders the frontmatter `title` as `<h1 class="post-title">`. 11 EN posts
additionally carried a manual `# Heading` as the first body line — producing a **second `<h1>`**
with the same text:

```html
<h1 class="post-title entry-hint-parent">When to Hire Your First Contractor (and When Not To)</h1>
<h1 id="when-to-hire-your-first-contractor-and-when-not-to">When to Hire Your First Contractor (and When Not To)</h1>
```

Verified against the theme source (`themes/PaperMod/layouts/single.html:6`) and by control group:
posts WITHOUT a body `# H1` render exactly **1** `<h1>`.

   unchanged**, only the duplicate element is gone.
