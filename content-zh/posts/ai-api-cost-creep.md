用 AI 打造產品的成本，正發生一件奇怪的事。每個頭條都在說價格崩跌——而這也沒錯。自 2023 年以來，每個 token 的費率已下跌約 97%，開放權重模型的花費如今只是前沿模型的一小部分。

然而，帳單卻悄悄地持續上漲。

Uber 在**四月**就把整年 2026 的 AI 編程預算花光了。微軟在啟用開發者 Claude Code 授權幾個月後又撤銷了它們。Priceline 的合約續約報價**貴了 4–5 倍**。據傳有一名工程師在一個月內燒掉了 $40,000 的 token 費用。隨著工具從「回答一個問題」漂移成「agent，去把任務做完」，每名開發者的 token 消耗量在九個月內上升了約 **18.6 倍**。

價目表沒有動。動的是計量表。

## 獨立開發者必須分清的兩個數字

每個人 AI 花費的背後，其實藏著兩條方向相反的曲線，它們講的是完全不同的故事。

**價格曲線在下跌。** 更大的上下文視窗、更便宜的推論、每一季都有新的開源挑戰者——「一單位智慧」的成本持續下降。如果你的用量是平的，帳單每個月都會變小。

**消耗曲線在攀升。** agent 不會只回答一次，它會迴圈。它會推理、重試、呼叫工具、重讀上下文，產出的 token 遠比單次聊天回覆來得多。每次查詢的 token 相較一年前上升了 2–4 倍，agent 迴圈把 token 再乘以 3–10 倍，而推理鏈又在輸出端疊加 5–10 倍。

價格下跌，乘上消耗上升，對那些沒在留意的人來說，乘積最後是往錯誤的方向走。這就是全部的解釋，值得坐下來想清楚：**你的 AI 帳單，其實是一個穿上定價外衣的消耗問題。**

## 是 agent 改變了計量表

在 agent 出現之前，一次請求是一件固定、可預測的事：一個提示詞進去，一個答案出來。你可以為它定價、編預算，然後不再去想它。

agent 打破了這個假設。同一個高層目標——「修好失敗的測試」、「研究這個主題」、「產出報告」——變成一個會一直跑到它認定自己完成為止的迴圈。每一次迭代都會花掉輸入、輸出和上下文 token。失敗三次再重試，計量表就跑了你預期的三趟。

這正是 TechCrunch 在 2026 年年中記錄的那條曲線——「token 帳單該買單了」從工程註腳，變成了董事會的恐慌。一次自主 agent 執行所消耗的，可能抵得上過去一整個禮拜的互動式對話。Jellyfish 的數字把這個取捨講白了：用最多 token 的工程師，生產力只比輕度使用者高約 **2 倍**，卻為了這點差距燒掉 **10 倍的 token**。

對獨立開發者來說，沒有財務長來吸收這份意外。你**同時是**那個財務長、那個工程師，以及那個買單的人。

## 錢到底花在哪（以及沒有花在哪）

剝掉炒作，一張上漲的 AI 帳單背後是四個誠實的驅動因素，大致按它們悄悄花掉你多少錢排序：

1. **送出沒用到的上下文。** agent 和 RAG 管線把整份檔案、整段歷史、整份文件塞進每一次呼叫，不管任務需不需要。上下文 token 就是輸入 token，每一次呼叫都以全額計費。
2. **拿前沿模型去做它大材小用的任務。** 精準度貴了大約 10–100 倍。一項便宜開源模型就能完美完成的摘要或分類任務，不需要用旗艦模型。
3. **沒有快取、沒有重試紀律。** 提示詞快取能把重複的前綴從全價變成不到一美分。不用它，就等於為同一段系統提示詞付了一萬次錢。
4. **衡量的是你出貨了什麼，而不是你用了什麼。** 會嚇到人的帳單，都是那些直到月底才看見的帳單。在端點上測量、在門檻上告警，「意外」就變成你早已規劃進去的一筆項目。

注意清單上**沒有**什麼：每個 token 的價格。因為那已經不是你的問題了。

## 把計量表拿回來的紀律

解方不是「少花點錢在 AI 上」，而是讓模型對應任務、盯住計量表，而不是價目表。

- **路由到最便宜、但夠用的模型。** 把困難的推理路由給強模型，把普通的工作交給便宜的模型。這正是大型實驗室內部在做的事——在不需用到頂級模型時，把 Opus 呼叫降級到 Sonnet 或 Haiku。獨立開發者免費就能拿到同一根槓桿。
- **積極使用快取。** 把系統提示詞、工具 schema 和穩定上下文放到提示詞快取後面，不再重複購買同樣的 token。
- **限制輸出、限制迴圈。** 為一次執行可以花多少 token、一個 agent 可以迭代幾次設下預算。一個沒有邊界的迴圈，就是通往四位數意外帳單最快的一條路。
- **衡量「出貨」對比「消耗」。** 重要的數字不是「我花了多少」，而是「我花掉的，有多少真正到了使用者手上」。如果你看不到這個切分，就是帳單在駕馭你，而不是你在駕馭帳單。

這些都不是什麼高深的東西。它跟獨立開發者套用在伺服器、代管和每一支早已購買的 API 上的成本紀律，是一模一樣的。AI 之所以感覺不同，只是因為計量表是新的——而新的計量表，總要等到第一張帳單寄來，才會被人正眼看待。

## 十年尺度的重點

價格崩跌是真的，而且它是一份禮物：正是它讓一個人能做出過去需要一整個團隊才做得出的東西。但「AI 便宜到我不用去思考它」的時代已經結束了——而且在大多數獨立開發者還沒察覺之前就結束了。

把 token 花費當成它本來就是的成本結構來看待的開發者，才會在話題從「它能做什麼」轉向「它要花多少錢、我看不看得到計量表」的時候，繼續獲利地出貨。

這才是現在的全部遊戲。不是盯住價目表。是盯住計量表。
